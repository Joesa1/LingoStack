翻译模型

连接你自己的 API

选择服务商，填写密钥和模型。译文由你选择的服务商生成。

接口地址与协议

中转服务选择其文档要求的协议。API 地址可以填写到 /v1，不必包含 /chat/completions。

密钥保存在此浏览器本机，不同步到云端，不发送给网页。所选文字和字幕会发给你配置的模型服务商。测试翻译也会产生一次 API 请求。

字幕朗读

用本机声音听译文

Mac 使用系统提供的声音，不需要另付语音 API 费用。

开启后，长句来不及读完时会暂缓视频；关闭后保持视频连续播放，过时的朗读会被替换。拖动进度会清空旧朗读。

双语字幕预览世界比你想象的更广阔。

The world is wider than you think.

若没有合适的声音，请在 macOS 系统设置的朗读功能中下载对应语言声音，再重新打开此页。视频中是否开启字幕与朗读，在扩展弹窗里控制。
