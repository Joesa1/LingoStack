# 译伴视频预处理 0.3.0（Mac）

解压后双击「启动译伴.command」。第一次启动会安装字幕与 MP3 组件，随后自动打开本地网页；无需安装 Chrome 扩展，也不要直接打开 index.html。

需要 Python 3.10 或更新版本。如启动提示缺少 Python，安装 https://www.python.org/downloads/macos/ 后重试。随包附有 Apple Silicon（M1/M2/M3/M4 等）Mac 的 Node 运行时。Intel Mac 需要另行构建运行时包。

1. 选择 DeepSeek，填写你的 DeepSeek API Key。
2. 点击「获取模型列表」，选择模型；也可以手动输入账户支持的模型 ID。
3. 点击「测试连接」，确认成功。
4. 粘贴 YouTube 普通视频或 youtu.be 短链接，点击「获取字幕并翻译」。
5. 等待字幕获取和分段翻译，可查看中英全文、下载中文 TXT。失败后可重试；相同模型保留已经完成的翻译段。

本版支持链接自动获取字幕、中文全文、单人 MP3 和双人配音 Beta，不包含无字幕 ASR 或 BBC。长视频会分段请求模型，不把整部视频一次发送。一次处理一个任务。关闭网页不取消任务，关闭启动终端会停止服务；重新启动后失败任务可以恢复。

优先获取英文字幕，无英文时选其他现有字幕。读取器使用 youtube-transcript-api 和 yt-dlp；YouTube 限流、登录要求、区域限制、无字幕和网络故障可能导致获取失败，本版不会读取浏览器 Cookie。

API Key 只在运行内存中使用，不写盘。不读取扩展里已经保存的 Key。任务保存在 ~/Library/Application Support/LingoPreprocess，可备份此目录；只监听本机 127.0.0.1:18743。

Provider 和四种翻译协议复用 Chrome 扩展的源码。页面以文本方式显示模型输出，不把字幕或标题当作 HTML 执行。

项目来源：
- https://github.com/jdepoix/youtube-transcript-api
- https://github.com/yt-dlp/yt-dlp

## 0.2.1 修复

长字幕翻译和连接测试现在最多等待 3 分钟，不再沿用扩展划词请求的 25 秒限制。页面显示当前翻译段，任务失败时会清除旧的“正在获取字幕”提示。超时不会自动重复计费请求；相同配置下点击重试从未完成段继续。

升级：先在旧启动终端按 Control+C 停止旧服务，再解压此版，双击启动译伴.command，刷新页面并重新填写 Key。旧任务保存在同一本机目录，无需重新获取字幕；点击原失败任务的重试即可。

回归验证：模拟模型故意等待 28 秒后返回，验证超过旧截止时间仍能完成全文及导出；四种协议均验证等待上限和响应正文超时。此验证不等于真实 DeepSeek 长文本调用已验证。

## 0.3.0 音频验证步骤

1. 关闭旧启动终端，在新文件夹双击启动译伴.command。首次会安装 MP3 编码组件 imageio-ffmpeg（https://github.com/imageio/imageio-ffmpeg）；保留启动终端。
2. 旧视频会自动出现。在「3. 音频制作」选择阿里云百炼，填写你插件使用的语音 Key、对应区域和模型。选择音色 A，点击「试听 A」。翻译 Key 和语音 Key 不共用。
3. 选择已翻译视频，保留「单人完整朗读」，点击「试听开头片段」，满意后点击「生成 / 继续 MP3」。完成后点击「播放 / 下载完整 MP3」。
4. 多人配音 Beta：选择该模式，填写上方翻译服务配置，点击「自动整理角色台词」。程序只让模型判断角色，保留原台词内容。角色 A/B 归属均为推测，需核对并可直接编辑；目前限两种音色。给 A/B 选择不同音色，再试听和生成。
5. 停止或失败后，同样的台词和语音配置可继续生成，已完成片段不会重复请求。修改任何台词、音色或语音配置会生成新的音频版本。开始合成后的角色台词会保存在任务中；尚未提交的编辑在刷新后丢失。

语音生成每段最多等待 3 分钟。合成片段先统一为 24 kHz 单声道 WAV，最后编码为 96 kbps MP3。按句分段而非视频时间轴，保留合成音频的句间停顿；仍可能存在段落间音色韵律差异。本版不克隆原声、不保证角色识别准确。系统朗读仅适合浏览器播放，本版导出仅支持三家云端服务。

验证：真实 FFmpeg 对模拟语音片段完成 MP3 编码并解码检查；验证 A/B 音色分配、继续生成时缓存复用、修改音色后的缓存失效、任务中不保存 Key。未使用真实云端语音账号验证整篇听感，需你先试听确认。

0.3.0 浏览器回归还覆盖：三家语音服务下拉、角色草稿编辑、非法台词拒绝、通过模拟云端语音完成实际 MP3 下载；语音中断后只补做未完成片段。
